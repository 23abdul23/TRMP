# B.Tech thesis (IIIT Allahabad template) — TRMP project

Source of the thesis *Adaptive Destroy-and-Repair for the Total Rotation Minimization Problem: Reinforcement Learning and a
Contiguous-Destroy Improvement of ES-TRMP*. Built on the supplied `Thesis.cls` template.

Build (needs XeLaTeX, biber and the Noto Serif Devanagari font; the class uses polyglossia for the Hindi title line):

    latexmk -xelatex -interaction=nonstopmode main.tex      # -> main.pdf

Placeholders to fill in `main.tex` before submission: `\studentonename`, `\studentoneroll`, `\supervisor` (and optionally
`\studenttwoname`/`\studenttworoll`, ... for co-authors, which the front matter picks up automatically). The acknowledgements
in `frontmatter.tex` also contain `[Supervisor Name]`.

- `Chapters/` — 1 Introduction, 2 Literature, 3 Methodology, 4 Experiments and Results, 5 Discussion, 6 Conclusion
- `Appendices/` — A experiment catalogue and decisions, B per-instance table (generated by `../scripts/make_thesis_tables.py`), C code base and reproduction
- `refs.bib` — bibliography; `Figures/` — figures (generated by `../scripts/make_report_figures.py` and earlier scripts)
